# 复核结论

**总体：六项修正大部分接受，两项部分接受，一项保留异议。协调者推荐的 S0→S1→S2 收束点我同意。**

**第 1 项：接受，并更正我的表述。** 已核实 `results/final_thesis/c3_temperature_scaling_and_ensembles/classification/validation_exports/treesatai/` 下有 12 个 parquet。EuroSAT TS 目录下每 seed 只有 `test_predictions.parquet` 与 `metrics_and_manifest.json`，未见单独的 calibration split 预测文件，calibration 导出是否在别处我未定位，状态 UNKNOWN。分割 24 个 run 的 `predictions/` 下仍只有 `test`。因此"72 个新前向"过宽，应改为：TreeSatAI 验证集预测已有，EuroSAT calibration 预测待定位，分割验证集预测确实不存在。是否补前向按具体分析逐项决定，不预设总数。

**第 2 项：大部分接受，一处保留。** 接受：TS 后 AUROC 大幅变化不能定为必然 bug，应先按样本检查 logit 尺度差异再判断。接受：AUROC 不随正负比例变的性质只在固定类别条件分布下成立，换模型后错误集合本身变了，仍须并列报告错误率；E-AURC 只是相对 oracle 的修正，不是跨错误率的万用尺度。接受：≥50 正例不是定义门槛，改为对全部 15 个标签报支持数、区间和未定义量，小类不删。保留异议一点：TreeSatAI exact-match 错误率约 75% 时 AURC 在数学上有定义，但对"弃权能否降低风险"的解释价值很低，因为多数样本都算错。我建议把 sample-label 决策错误作为主口径，exact-match AURC 只作附录，理由是解释性而不是数学无效。

**第 3 项：接受。** 多分类 logit 有公共平移不变性，用中心化 logit 的范数加 margin 才有比较意义。DOFA–EuroSAT 六个历史 run 没有 deterministic 嵌入，用 MC run 嵌入不能再称 D 的 frozen/full 比较；要么单独报 MC run 的 CKA 并标明，要么补 6 次特征前向。后者属于新推理，只在写 CKA 这一分支时才需要。

**第 4 项：接受，收回过严表述。** Hessian 与 Jacobian 诊断需要梯度计算，不需要训练，我原来归类有误。RGB 通道遮蔽可以做，前提是先定义遮蔽后输入的信息含义与扰动语义，而不是原则禁止。模糊不必然改变分割真值，"只报内部像素"改为按任务与严重度检验标签保持，再决定是否分层。对 CloudSEN12 人工添云直接改变目标类语义，这一点仍成立。

**第 5 项：接受。** "每格再训 2 组"没有依据，重复次数应由想下的结论与所需精度定义，3 组也不保证普遍稳定。措辞统一改为"当前研究范围必要"，正式毕业必要性 UNKNOWN。

**第 6 项：接受。** 现行 29 项规范已把计算成本列为可补充项，不因此新增核心实验。条件化方案合理：若要写实测效率比较，必须新做统一计时；否则披露缺失并只报操作次数与实际口径即可。DE 成员推理时间求和缺聚合开销，也应照此披露。

**修订后的共同点。**

- 核心 3 RQ 可在已限定范围内写作，无需新训练、重算主指标或重开 24 组对照。
- 封存原件不动，另建更正阅读表处理 16 条过期 MC 备注与成本缺失。
- S0 核心写作，S1 现存预测的行为分析，S2 已有 D/TS 尺度诊断加熵与 Gini 代理的稳定性，均为 0 新前向 0 训练，到此收束。
- CKA、corruption 是分支；模块级训练与 AU/EU 已知生成参照只是更强结论的条件要求。
- 所有 PASS 表示范围内证据可复核，不表示学位验收。

**仍保留的两点。** 一是 TreeSatAI exact-match AURC 的低解释价值，见上文第 2 项。二是 S1 的分析说明仍应在运行前写好并标注日期，因为测试集已被反复查看；这不叫预注册，但能约束事后选择分数与阈值。这两点都不影响收束点。
